用中文輔助閱讀英文文獻

上傳 PDF 後，直接在文件中選取英文單字、專有名詞或句子，側邊欄會顯示繁體中文翻譯；若是專有名詞，還會簡述它在實驗或研究中的意義。查過的詞會自動收進依研究方向分類的生詞表。

把 PDF 拖曳到這裡

PDF 只在你的裝置上開啟，不會上傳；只有你選取的文字（與周圍一小段上下文）會送給 Claude 翻譯。

    設定

    翻譯來源

    免費來源適合查專有名詞：顯示維基百科的中文條目名稱與摘要，以及 PubMed 上的相關文獻；無法翻譯句子，一般單字的效果有限，也不會自動分類生詞。
    Claude 會依上下文翻譯單字、專有名詞與句子，並自動把生詞分類。

    Claude API 金鑰

    使用 Claude 需要你自己的 Anthropic API 金鑰（與 Claude 訂閱分開計費）。金鑰只存在這台裝置的瀏覽器裡，不會上傳到其他地方。

    生詞表備份

    生詞表存在這台裝置上。要搬到另一台裝置（例如手機），先在這裡匯出備份檔，再到另一台匯入；匯入會與現有生詞合併。
